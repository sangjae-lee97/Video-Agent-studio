## 움직임·제작·검토 지시

### M01 — 약부터? 시술부터? 질문과 대상 한정

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N01, N02
- 시작 → 끝: 두 첫 치료 전략의 질문 → 7일을 초과한 시간선
- 움직임: 질문 양쪽에 약물·시술을 배치하고, 7일 눈금을 따라 지속 기간을 펼친다.
- 라벨: 약물 / PFA / 지속성 심방세동 · 7일 초과
- 검토: 기간 도식은 설명용. 심장 박동 그래프를 실제 측정값처럼 쓰지 않는다.

### F01 — 단면과 카테터 펄스의 개념

- 선택 이유: 단면 깊이와 표적 부위 공개에 입체 생성 장면 사용
- 음성 연결: N03
- 시작 → 끝: 분리 전 좌심방 개념 모형 → 카테터 펄스 근접 화면
- 움직임: Flow 프롬프트의 세 샷 참조
- 라벨: 프롬프트의 RED GRAPHICS 참조
- 검토: 원본 3샷 확인. 마지막 선은 심실 쪽으로 연장돼 표적 컷으로 제외. 후벽은 M-PV 도식으로 보여준다. 수정 프롬프트는 재생성용이며 현재 재료의 생성 프롬프트와 구분.

### M-PV — 폐정맥 입구와 좌심방 후벽을 개념도로 구분

- 선택 이유: 제공 영상 세 번째 샷의 표적 위치 수정
- 음성 연결: N04
- 시작 → 끝: 좌심방 뒤쪽을 펼친 개념도 → 네 입구와 중앙 후벽 강조
- 움직임: 네 입구에 강조 고리를 그리고 중앙 후벽 영역을 드러낸다.
- 라벨: 폐정맥 주변 / 좌심방 뒤쪽 벽
- 검토: 전기장 범위와 실제 병변 크기를 나타내지 않는다.

### M02 — 310명의 비교 구조

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N05, N06
- 시작 → 끝: 중심 모집단 → 두 연구군
- 움직임: 310명 모집단의 점들을 무작위 배정 구조에 따라 207개와 103개로 분리한다. 두 군의 숫자는 각 발화 때 공개한다.
- 라벨: 무작위 배정 310명 / PFA 207 / 약물 103
- 검토: 무작위 배정 애니메이션은 실제 개인 정보가 아닌 개념도. 310개 사람 아이콘 나열 금지.

### M03 — 관찰 기간을 눈으로 연결

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N07
- 시작 → 끝: 모니터 아이콘 → 12개월 도착
- 움직임: 작은 모니터 아이콘에서 점선이 타임라인으로 이어지고 추적 커서가 12개월에 도착한다. 타임라인 눈금이 순서대로 강조된다.
- 라벨: 삽입형 심장 모니터 / 12개월 추적
- 검토: 점선은 데이터 전달 개념. 심전도처럼 임의 파형을 환자 실측으로 표시하지 않는다.

### M04 — 효과 차이를 드러내기

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N08, N09
- 시작 → 끝: 같은 기준축 → 두 막대와 차이 괄호
- 움직임: 0~100% 공통 축 위 두 막대가 0에서 56과 30으로 자란다. 값 도착 후 두 끝점 사이 괄호가 그려지며 약 26%p로 전환한다. 끝 3초에는 추정치라는 설명이 펼쳐진다.
- 라벨: 1년 치료 성공 추정치 / PFA 56% / 약물 약 30% / 약 26%p 차이 / Kaplan–Meier
- 검토: 세로축 잘라 차이를 과장하지 않는다. 56%를 128/207 단순 계산값이나 완치율로 쓰지 않는다.

### M05 — 높은 숫자의 의미를 바로잡기

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N10
- 시작 → 끝: 효과 수치 카드 → 평가 기준으로 이어지는 카드
- 움직임: 앞 장면의 56% 막대가 작은 카드로 이동한다. 치료 성공이라는 제목 아래 완치와 같지 않다는 부등호가 그려지고 조건 카드가 펼쳐진다.
- 라벨: 치료 성공 ≠ 완치
- 검토: 완치라는 말에 승리 도장이나 환자 회복 연기를 붙이지 않는다.

### M06 — 복합 기준을 단계로 설명

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N11, N12
- 시작 → 끝: 빈 시간축 → 조건을 갖춘 평가도
- 움직임: 0~90일과 90일~12개월 구간을 순차로 펼친다. 커서가 이동하며 초기 성공, 기준에 해당하는 재발, 추가 치료 조건 세 항목을 차례로 강조한다. 5초에 시간축에서 조건 목록으로 전환한다.
- 라벨: 초기 성공 / 90일 이후 재발 기준 / 추가 시술·약물 조건 / 군별 기준 차이
- 검토: 약물군과 PFA군의 약물 조건이 동일하다는 그림 금지. 체크 표시는 모든 참여자가 통과했다는 의미로 쓰지 않는다.

### M07 — 효과에서 위험으로 질문 전환

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N13
- 시작 → 끝: 효과 카드 → 효과와 안전성 병렬
- 움직임: 효과 막대 카드가 왼쪽으로 축소되고 오른쪽에 안전성 카드가 진입한다. 두 카드 사이 이동선이 그려지며 질문 문구가 등장한다.
- 라벨: 그렇다면 모두 시술부터? / 안전성도 함께
- 검토: 효과%와 이상사건%를 빼거나 같은 지표로 합치지 않는다.

### M08 — 안전성 분모를 분명히

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N14
- 시작 → 끝: 안전성 모집단 → 13/257 강조
- 움직임: 별도 안전성 모집단 제목이 펼쳐지고 257의 분모가 먼저 나타난다. 그 안에서 13과 5.1%가 순서대로 강조되며 주요 기기·시술 관련이라는 범위가 밑줄로 연결된다.
- 라벨: PFA 안전성 분석 257명 / 13명 · 5.1% / 기기·시술 관련 중대한 이상사건
- 검토: 207명 배정군과 다름을 표시. 전체 중대한 이상사건 비율과 혼동하지 않기.

### M09 — 사건이 연구 중단으로 이어짐

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N15
- 시작 → 끝: 안전성 결과 → 중단 지점
- 움직임: 앞 카드에서 뇌졸중 6명 라벨이 분리된다. 연구 진행선이 일시 중단 지점에서 멈추고 이어 화면이 안전 점검 항목으로 전환되기 시작한다.
- 라벨: 뇌졸중 6명 / 연구 일시 중단
- 검토: 극적인 뇌 손상 재연이나 확인 안 된 혈전 이동 원인 영상 금지. 멈춘 선만 오래 홀드하지 않는다.

### M10 — 보완 조치를 순서대로 공개

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N16, N17
- 시작 → 끝: 중단 지점 → 보완 조치와 재개
- 움직임: 대상 선정, 시술 전 검사, 항응고 관리의 세 항목이 3초 간격으로 진입하고 연결선이 그려진다. 마지막 연결선이 연구 재개 노드로 이어진다.
- 라벨: 선정 기준 강화 / 시술 전 검사 / 항응고 관리 / 연구 재개
- 검토: 구체 약물 용량·시술 지시를 새로 만들지 않는다. 수정만으로 위험 0%가 된다는 초록 배지 금지.

### M11 — 보완과 안전성 확정은 구분

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N18
- 시작 → 끝: 연구 재개 → 남아 있는 불확실성
- 움직임: 재개 노드가 오른쪽으로 이동하지만 불확실성 괄호는 남아 화면을 가로지른다. 위험 해소를 확정할 수 없다는 한 문장이 단계적으로 강조된다.
- 라벨: 보완 ≠ 위험 해결의 증명
- 검토: 무사건 관찰만으로 인과를 확정하지 않는다.

### M12 — 처음 질문에 조건 있는 답

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N19, N20
- 시작 → 끝: 약물과 PFA 두 선택지 → 조건 있는 결론
- 움직임: 첫 장면의 두 선택지 구도로 돌아간다. 효과 근거 카드와 위험 고려 카드가 나란히 정렬되고 두 선이 개인별 판단으로 연결된다. 마지막 0.3초에는 새 정보를 시작하지 않는다.
- 라벨: 효과의 근거 / 위험 고려 / 누구에게 먼저 할지는 함께 판단
- 검토: 모든 환자에게 시술 우선을 권고하는 결말 금지.
