- 선택 이유: 기존 파일에서 해당 프레임을 정상 속도로 편집
- 음성 연결: N01, N20
- 시작 → 끝: 심장 전경 → 두 선택지
- 움직임: 도입은 첫 92프레임, 끝 질문 회수 때 첫 15프레임을 다시 쓴다. 도입은 후보 상태다.
- 라벨: 약과 시술 중 무엇을 먼저 할까
- 검토: 출처와 인·아웃, 승인 내레이션을 대조한다.

### M02 — 310명의 비교 구조

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N05, N06
- 시작 → 끝: F03 마지막 좌심방 그림 → 두 치료군의 공통 리듬 추적으로 연결
- 움직임: 15.625초 F03 좌심방 그림을 왼쪽 PFA 항목으로 축소하며 상단에 질문을 한 번만 조판한다. 17.980초 공통 입구에 310명. 18.775초부터 왼쪽 PFA 시술 207명과 오른쪽 약물 치료 103명을 함께 표시한다. 알약 아이콘은 오른쪽 라벨 끝에만 고정한다. 작은 환자 표식이 열린 두 경로로 이동한다. 20.460초 왼쪽, 22.230초 오른쪽을 발화에 맞춰 강조하고 24.500초까지 같은 배치를 유지한다.
- 라벨: 약보다 시술을 먼저 하면? / 310명 / PFA 시술 207명 / 약물 치료 103명
- 검토: 입구 앞 310명과 두 고정 라벨을 한눈에 읽고 좌우가 뒤바뀌지 않는지 확인한다. 질문의 철자·중복과 알약 위치도 검수한다.

### M03 — 관찰 기간을 눈으로 연결

- 선택 이유: 사용자가 채택한 v3 F05와 한국어 자막을 합성한다.
- 음성 연결: N07
- 시작 → 끝: 가슴 모형에 드러난 기록기 → 기록 시간축과 승인 자막
- 움직임: 선택한 1080p 영상의 피하 단면에서 시간축으로 전환한다. 소스 0–4.625초를 정상 속도로 사용하고 전체 27.240초에 기간 자막을 표시한다.
- 라벨: 승인 자막 N07 · 일 년 뒤 결과를 비교했습니다.
- 검토: 소스 전체 디코딩 및 컷 전후 확인. 마지막 샷은 첫 샷보다 흉곽 노출 범위가 넓다. 사용자가 해당 테이크를 채택했다. 본편 합성 대기.

### M04 — 효과 차이를 드러내기

- 선택 이유: 정확한 숫자·관계·조건을 수정 가능한 움직이는 도식으로 설명
- 음성 연결: N08, N09
- 시작 → 끝: 같은 기준축 → 두 막대와 차이 괄호
- 움직임: 0~100% 공통 축 위 두 막대가 0에서 56과 30으로 자란다. 값 도착 후 두 끝점 사이 괄호가 그려지며 약 26%p로 전환한다. 끝 3초에는 추정치라는 설명이 펼쳐진다.
- 라벨: 1년 치료 성공 추정치 / PFA 56% / 약물 약 30% / 약 26%p 차이 / Kaplan–Meier
- 검토: 세로축 잘라 차이를 과장하지 않는다. 56%를 128/207 단순 계산값이나 완치율로 쓰지 않는다.

### M05 — 높은 숫자의 의미를 바로잡기
