## 디자인 언어
- 재질/질감: 무광 흑연색 계측기 전면 패널, 헤어라인 브러시드 알루미늄 베젤, 앰버 7세그먼트 판독창(약한 발광), 흡음 쐐기 패턴(배경에 아주 옅게)
- 형태 언어: 직각 패널 + 작은 모서리(4px), 원형 다이얼·노브, 수평 레벨 바, 정밀한 기계식
- 선 스타일: 0.5~1px 눈금선(밝은 회청), 트레이스는 2px 발광선, 마커는 세로 실선
- 화면 밀도: 중간 — 패널 1~3개, 판독값 하나가 주인공
- 움직임 성격: 정밀·절도 — 바늘은 감쇠 진동 후 정착(오버슈트 소량), 레벨 바는 빠르게 오르고 피크 홀드, 판독값은 숫자 롤링 후 고정
- 분위기: 정밀한·조용한·긴장감
- 팔레트: 배경 #23292F(흑연) / 패널 #2E353D / 베젤 #A9B1BA / 주 글자 #E6EAEE / 판독 앰버 #FFB23E / 통과 초록 #46D483 / 오류 빨강 #FF5A4E / 프로브 A 하늘 #6EC6FF · B 앰버 #FFB23E · C 라일락 #B9A3FF / 보조 회청 #7F8B97
- 폰트: 제목 Noto Sans KR 900 / 본문 Noto Sans KR 700 / 숫자 DejaVu Sans Mono Bold(판독창, 글자 간격 넓게)

## 구성 요소
- 프레임/컨테이너: 계측기 전면 패널(좌상단 채널 태그, 우상단 작은 상태 LED)
- 챕터/라벨: 패널 상단 각인식 태그 “CH 01 · 소음” “RUN 1 · 16:36” (밝은 회청 각인 글자)
- 강조 그래픽: 앰버 발광 테두리(측정 중), 빨강 OVER 램프(오답), 초록 LOCK 램프(통과)
- 정보 그래픽: 레벨 바·LED 열(문항 수), 7세그먼트 판독(점수·dB·초), 다이얼(모드), 상단 시간축 트레이스(하루 진행선 — M07·M11에 같은 진행선 유지)
- 자막 사양: 프로젝트 공통(apply_captions.py). 모션 화면 하단 약 14%에는 핵심 요소를 두지 않는다.
- 전환: 채널 전환 — 패널 화면이 0.25s 동안 가로 스캔라인으로 지워지고 다음 채널이 켜짐. Flow ↔ 모션은 하드컷.
- 등장/퇴장: 패널은 전원 켜듯 밝기 0→1(0.3s), 판독값 숫자 롤링 0.6s, 바늘 0.8s 감쇠 정착
- 생성형 영상 배치: 전체 화면 하드컷. Flow 위 라벨 보정 외에는 얹지 않는다.
- 금지 효과: 파티클 폭발(burst), 발광 맥박 남발(점수 확정 2회만 허용), 화면 흔들림(OVER 램프 1회 이하), 튀는 이징·회전 등장, 디졸브. 배경 파티클은 쓰지 않는다. 표시등 위치에 실제 문항 순서가 있는 것처럼 보이지 않게, 통과/실패 칸은 통과부터 채운다.
