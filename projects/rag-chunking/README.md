- 확인함: 프레임 수·길이, 장면 순서, 20+8개 시점 프레임과 자막 겹침, 통합 음량 −17.8 LUFS, 썸네일 320×180 가독성.

- 오디오: 최종 마스터에서 alimiter(−1 dBFS 한도) 적용 — 원본 포화 65샘플 대응. 내레이션 보정 정책과 별개의 마스터 단계 처리.
- 청취 확인 대기: 5번(임베딩), 12번(재귀), 18번(영 점 육일일 — ASR은 0.61로 들음; 자막은 대본대로 0.611), 25번(템퍼러처, 대본 '일관돼지지만'은 비문 → 자막은 '일관되지만').
