# 템플릿 스펙: 물류 센터 출고 라인

## 메타포
물류 센터 출고 라인 — 질문 하나(주문서)가 맞는 근거(상자)를 찾아 검수를 거쳐 답(출고)이 되기까지, 한 경로를 따라가는 영상이라서.

| 래그 개념 | 물류 센터에서 |
|---|---|
| 질문 | 주문서(모델 코드가 적힌 주문 카드) |
| 파싱 | 입고된 매뉴얼을 풀어 내용물 확인 |
| 청크 | 상자(내용물: 수치+조건+각주를 한 상자에) |
| 메타데이터 | 송장 라벨(문서·페이지·버전·적용 모델 칸) |
| 모델 필터 | 적용 모델 칸으로 레인 분기 |
| 벡터 검색 | 비슷한 물건끼리 모인 선반 구역 |
| BM25 | 바코드·품번 스캐너 |
| RRF | 두 피킹 목록을 순위로 합친 한 장 |
| 리랭킹 | 검수대에서 다시 줄 세우기 |
| Supabase | 창고 랙(행·열이 있는 보관대) / 파이썬 = 옆 작업대 |
| 인용·검증 | 출고 상자에 붙은 송장 번호 대조 |
| 보류 | "재고 확인 불가" 도장 |
| 캐싱 | 자주 나가는 상자를 앞칸에 |
| 리라이트 | 주문서 문구를 창고 품명으로 옮겨 적기 |
| 평가 | 출고 품질 검사표·스톱워치·비용 전표 |

## 디자인 언어
- 재질/질감: 크라프트지 상자 면, 흰 감열 송장 라벨, 바코드, 도장 잉크(살짝 번짐)
- 형태 언어: 각진 직사각형(상자·라벨), 모서리 2px 라운드, 바닥 레인 표시선
- 선 스타일: 송장 칸막이 가는 실선(1.5px 남색), 이동 경로는 바닥 안전선 같은 굵은 점선
- 화면 밀도: 중간 — 한 화면에 상자/라벨 3~6개, 여백은 크라프트 배경
- 움직임 성격: 컨베이어처럼 일정 속도로 수평 이동 + 도장은 짧은 스냅(80ms 눌림)
- 분위기: 밝은·정돈된·실용적
- 팔레트: 배경 #EFE6D6(크라프트 밝은 톤) / 주색 #23395B(남색 글자·선) / 보조 #FFFFFF(라벨) / 강조 — 안전 노랑 #F2B400(적용 모델·주의), 청록 #138A8A(벡터), 주황 #E2701E(BM25), 초록 #2E8B57(정답·통과), 빨강 #C8372D(오답·보류)
- 폰트: 제목 Noto Sans KR 900 / 본문 Noto Sans KR 700 / 숫자·코드 JetBrains Mono 계열 모노(송장 인쇄 느낌, 없으면 Noto Sans Mono)

## 구성 요소
- 프레임/컨테이너: 흰 송장 라벨(상단 굵은 칸 = 제목, 아래 칸막이 필드), 크라프트 상자 정면
- 챕터/라벨: 장 시작마다 상자 옆면에 찍히는 스텐실 번호 "STATION 02 · 자료 준비"
- 강조 그래픽: 노랑 형광 라벨 테이프(단어 뒤에 붙음), 도장(통과 초록 / 보류 빨강), 빨간 X 테이프
- 정보 그래픽: 순위표 = 피킹 목록(행 번호·체크칸), 수식 = 감열지 영수증 출력, 지표 = 품질 검사표 칸 채우기, 시간 분포 = 바닥 레인 위 상자 도착 시각
- 자막 사양: 프로젝트 공통(apply_captions.py, Noto Sans KR 900 흰 글자·외곽선, 하단 중앙). 모션 화면 하단 약 14%에는 핵심 요소를 두지 않는다(자막 겹침 방지는 화면 설계로만).
- 전환: 컨베이어 슬라이드(오른쪽→왼쪽, 0.4s) 기본, 장 전환은 상자 뚜껑 닫힘(0.5s)
- 등장/퇴장: 라벨은 프린터에서 나오듯 위→아래 0.35s easeOutCubic, 도장 0.08s 눌림+0.15s 잉크 번짐
- 생성형 영상 배치: 전체 화면 하드컷. Flow 위에 모션을 얹지 않는다(라벨 보정 제외).

## 타이밍 규칙
- 기본 등장 길이: 0.35s
- 강조 그래픽(테이프 붙이기/밑줄) 길이: 0.4s
- 장면 전환 길이: 0.4s (장 전환 0.5s)
