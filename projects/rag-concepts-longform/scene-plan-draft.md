# 장면 배분 초안 (합성 전 — 실제 시각은 보정 음성 실측 후 확정)

사용자 합의(2026-11-20): Flow는 장마다 1~2개, 나머지는 모션그래픽. 초안 Flow 14개 × 약 8초 ≈ 110초 / 약 640초 ≈ 17%. 공통 지침의 30%보다 낮은 것은 롱폼에 대한 사용자 결정.

| 장 | Flow (하드컷, 8초) | 모션그래픽 |
|---|---|---|
| 0 오프닝 | F01 번호 한 글자 다른 두 프린터(명판 0/8) · F02 거대한 물류 센터에 주문 카드 한 장 입고 | 세 덩어리 지도(준비→찾기·답하기→평가) |
| 1 래그 | — | R·A·G 세 정거장 라벨, 기억만으로 답하기 vs 근거로 답하기 |
| 2 자료 준비 | F03 매뉴얼을 풀어 내용물을 상자에 나눠 담고 송장 라벨을 붙이는 작업대 | 파싱 깨짐(표 행·열 뒤섞임), 도구 비교·원문 대조, 청킹 원칙(한 상자에 수치+조건+각주), 50매 예시(라벨 '예시'), 송장 필드 채우기, 모델 필터 레인 |
| 3 검색 | F04 선반 구역을 도는 피킹(벡터) · F05 바코드 스캐너가 품번을 읽음(BM25) | 임베딩 좌표, 숫자에 뜻 없음, 0.9≠90%, BM25 세 요소, Kiwi 토큰화, 점수 단위 불일치, RRF 영수증 계산(k=60), 리랭킹 검수대, A/B/C 세 레인 |
| 4 Supabase | F06 랙(행·열 보관대)과 옆 작업대 | 테이블 칸, pgvector, ts_rank≠BM25, 방법 A 역할 분담도, 미리 만든 검색용 자료 재사용 |
| 5 생성·검증·보류 | F07 출고 상자 송장 번호 대조 · F08 빈 선반 앞 "재고 확인 불가" 도장 | 입력 3요소, 인용 vs 검증 체크 3칸, 교차 모델 인용 X, 실패 원인 4갈래 |
| 6 최적화 | F09 자주 나가는 상자를 앞칸 선반으로 | 캐시 키(모델+질문) 일치/불일치, 무효화, 리라이트 품명 변환표, 보존 항목 |
| 7 전체 경로 | F10 주문 카드가 컨베이어를 따라 여러 정거장을 지나는 추적 샷 | 경로 지도에 단계 점등, 로그 전표 |
| 8 평가 | F11 출고 품질 검사(클립보드·스톱워치) | Hit@5, 답변/근거/거부 정확도 검사표, P50/P95 분포, 토큰·비용 전표, 성공률 vs 정확도, 공정 비교 고정 칸 |
| 9 마무리 | F12 맞는 프린터 앞에 맞는 상자가 도착 | 전체 정거장 한 장 요약 |

남은 결정: F01·F12 사이 프린터 외형 연속성, Flow 클립 수(12~14) 최종 확정은 실측 후.
