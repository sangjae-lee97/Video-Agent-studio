## 핵심 질문

**“이름이 숫자 하나 다른 프린터들 사이에서, AI는 ‘내 모델’의 답을 근거와 함께 골라낼 수 있을까?”**
끝에서 시청자가 답할 문장: 좋은 기술지원 에이전트는 맞는 모델의 공식 근거로 답하고, 근거가 없으면 모른다고 말한다 — 그리고 그것을 정확도·근거·속도·비용으로 측정한다.

## 시청자가 알아야 할 배경

- RAG Agent: 질문과 관련된 문서를 검색해 그 근거로 답하는 프로그램(G 서두, §2).
- 이 과제의 어려움: 한 PDF에 다섯 모델이 함께 들어 있고, 표의 행·예외 각주마다 적용 모델이 다르다(G§2 목표1, §3 “문서·절·표 행의 적용 모델을 구분”).

## 이야기 순서

1. 질문: 숫자 하나 다른 두 모델(DCP-T830DW / DCP-T835DW — 지정 모델 표 3·4번).
2. 과제 정체: 3~4명, 5일 40시간, 10개 모델, 공식 PDF 2종.
3. 함정: 한 권에 다섯 모델 → 다른 모델의 절차를 가져오면 그럴듯한 오답(교차 모델 인용).
4. 대응: 청크마다 문서 ID·페이지·적용 모델 메타데이터 → 역추적.
5. 검색기 3종 비교: Vector / BM25+Vector Hybrid / Re-ranking.
6. 반전: 자료에 없는 질문 → 거부가 정답. 반대로 답이 있는 질문을 거부하면 오답.
7. 효율: 캐싱 또는 쿼리 리라이트, 생성 모델 2개 이상 비교.
8. 평가: 공개 10 → 비공개 100문항, 유형별 문항 수, 배점 45점, 0.40 미만이면 효율 0점, 60초 제한.
9. 재현: 다른 팀원이 다시 실행.
10. 결말: 첫 질문으로 복귀.

## 불확실·제외

- DCP-T830DW와 DCP-T835DW의 실제 기능 차이는 가이드에 없다. 영상에서는 “이름이 숫자 하나 다르다”는 사실만 쓰고 기능이 다르다고 단정하지 않는다(“다를 수 있다”까지만).
- FAQ 조사 수치(4/10 등록, 452건, HTTP 403)는 선택 자료 관련 세부라 대사에서 제외한다(화면에도 넣지 않음).
- 비공개 평가 시점·예산은 운영 공지 사항이라 다루지 않는다.
- Brother 로고·제품 사진은 사용하지 않는다(상표·실제 제품 외형 재현 회피). Flow에는 브랜드 없는 일반 프린터로 지시한다.
