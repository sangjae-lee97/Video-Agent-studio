# 내레이션 음량·호흡 처리 도구 조사

확인일: 2026-11-19. 공식 문서와 GitHub README 조사이며 설치·실행·한국어 청취 검증은 하지 않았다. 제작 도구 채택이나 기존 보정 정책 변경을 의미하지 않는다.

**후속 사용자 결정:** Auphonic은 추가 API를 원하지 않아 제외했다. 아래 서비스 추천은 조사 당시 의견이며 현재 다음 작업이 아니다. 로컬 처리 원칙과 실제 후속 실험은 [로컬 자동화 기준](LOCAL_AUDIO_POLICY.md)을 따른다.

## 조사 이유

사용자가 relative-phrase-v1의 “103명은”이 여전히 작다고 지적했다. 현재 코드는 “103명은 약물” 전체 RMS가 주변보다 약 0.80dB 작아 1dB 허용 범위 안이라는 이유로 유지한다. 이는 작은 발음 자체가 충분히 크다는 증거가 아니다. 구절 평균에 짧은 발음이 가려질 수 있고, VAD는 호흡 전용 분류기가 아니다. 새 임계값을 계속 추가하기 전에 전용 도구를 비교한다.

## 후보와 근거

| 후보 | 공식 설명에서 확인한 기능 | 현재 용도와 한계 |
|---|---|---|
| Auphonic Adaptive Leveler | 파일 내부 말소리 음량 조절, 숨·소음·침묵 분류 후 증폭 제외. API 제공 | 자동화 비교 우선 후보. 한국어 작은 발음 개선과 원본 호흡 유지 정도는 미검증 |
| narration-tools / BreathTamer | 무료 Windows 앱·VST3·CLI, 오프라인 분석, 호흡 검출·감쇠, 검출 구간 CSV 출력 | 호흡 처리 보조 후보. 작은 말소리를 올리는 완성형 레벨러는 아님. AGPL-3.0, 공개 검증 규모가 작음 |
| davidseegert/loudness-leveler | C++ 데스크톱 앱. Gain Rider의 반응 시간·분석 창·증폭 범위 조절, LUFS 분석 | 로컬 음량 추적 참고 후보. 호흡 처리는 음량 문턱을 쓰는 게이트라 작은 발음과 구분된다고 보장 못 함. CLI 연동 미확인 |
| FFmpeg speechnorm | 파형 반주기별 증폭·압축, 임계값과 반응 속도 조절 | 로컬 비교 기준으로 사용 가능. 문서상 호흡 전용 분류가 없으므로 단독 해결책으로 확정하지 않음 |

공식 출처: [Auphonic 알고리즘](https://us.auphonic.com/help/algorithms/singletrack.html), [BreathTamer README·CLI](https://github.com/robertmonroe/narration-tools), [Loudness Leveler README](https://github.com/davidseegert/loudness-leveler), [FFmpeg speechnorm](https://ffmpeg.org/ffmpeg-filters.html#speechnorm). GitHub의 기능 설명은 작성자 주장이다. 소스 감사·배포 파일 실행 검증을 마친 것으로 해석하지 않는다.

## Auphonic 비용·설정 주의점

- 무료 월 2시간, 무료 계정도 API 사용 가능. 무료 결과에 Auphonic 안내음(jingle)이 들어간다.
- 처리 1건당 최소 3분 크레딧 차감. 150초 영상도 최소 3분으로 계산하므로 무료 2시간은 재처리 없이 최대 40건이다. 유료 크레딧은 별도 검토한다.
- Fast Leveler(110%)는 빠른 음량 차이에 대응한다. Amplify Everything(120%)는 비발화 소음도 올리므로 이번 목적의 우선 후보에서 제외한다. 기본 설정부터 비교하고 Fast는 필요할 때 별도 비교한다.
- 기본/빠른 설정 모두 실제 발음·호흡 보존을 보장하는 것은 아니다. 전용 레벨러에는 압축·전체 음량 조정이 포함될 수 있어 현재의 '조용한 부분만 상승' 정책과 동등하지 않다.

출처: [요금·API·최소 처리 시간](https://auphonic.com/pricing), [Leveler 설정](https://us.auphonic.com/help/web/preset.html).

## 다음 비교 제안 — 아직 실행하지 않음

1. 같은 1.0배속 원본을 사용해 원본·현재 후보·전용 레벨러 결과를 비교한다. 기존 보정본을 다시 보정하지 않는다.
2. 20~27초의 “207명은 / 103명은”, 80~85초의 “다만 / 해결됐다고”, 여러 문장 끝 호흡을 함께 확인한다. 전체 파일도 확인해 다른 부분의 부작용을 놓치지 않는다.
3. 전체가 커진 효과와 구간 균형 개선을 구분해 청취한다. 작은 발음의 명료도, 자연스러운 억양, 숨소리 증폭, 볼륨 출렁임·자음 손상, 피크·길이를 평가한다.
4. 비용 우선이면 로컬 도구를 시험하되, BreathTamer 단독으로 음량 문제가 해결된다고 전제하지 않는다. 자동화 편의성 우선이면 Auphonic을 비교 기준으로 검토한다.

이번 조사로 설치·외부 음성 업로드·새 Typecast 합성·설정 변경은 수행하지 않았다. 기존 후보는 여전히 미승인 상태다.
