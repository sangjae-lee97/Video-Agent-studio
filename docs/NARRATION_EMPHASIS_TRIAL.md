# 내용에 따른 강조 재합성 — 2026-11-19 비교 실험

**최신 결정:** 사용자가 후속 로컬 보정본을 듣고 이 감정 배치 방식과 음량 보정 방식을 승인했다. [현재 기준](NARRATION_STYLE.md), [승인 기록](NARRATION_APPROVAL.json)을 따른다. 이 문서의 아래 내용은 생성 당시 실험 기록으로, 당시의 '미승인/청취 대기'를 현재 결정으로 읽지 않는다.

최신 피드백: 사용자가 전체적으로 괜찮다고 평가했으며 12~20초의 약한 말소리를 지적했다. 후속 요청에 따라 시작/끝 0.2초 보호를 유지한 공통 로컬 보정 후보를 원본 전체에 적용했다. `outputs/typecast-piljae-pfa-emphasis-1.0x-v1/local-short-window-v1/narration_balanced.wav`, 92.610초. [검사 결과](piljae-emphasis-local-level-results.json). 아래 원본 생성 기록과 후처리본을 구분하며, 보정본 청취는 아직이다. 향후 기본 속도·강도값의 자동 변경은 하지 않았다.

사용자가 음량 보정 대신 강조할 말에 감정을 배치해 전체를 다시 생성하자고 요청했다. 필재/SSFM 3.1, 현재 비교 중인 1.0배속, 피치 0, API target_lufs -18을 유지했다. 향후 제작 기본값 1.05배속을 바꾼 것은 아니다.

## 다른 원고에도 적용할 판단 기준

- 주장이나 비교를 이해하는 데 필요한 핵심 대상을 먼저 고른다. 이전 음성의 작은 특정 초를 강조 대상으로 삼지 않는다.
- 비교 수치의 양쪽은 같은 톤으로 읽는다. 유리한 결과 한쪽만 과장하지 않는다.
- 핵심 오해 정정, 제한 조건, 결론은 주변 설명과 분리된 의미 단위로 읽어 문장에 무게를 준다.
- 안전성·위험은 차분하게 전달하되 `tonedown`을 넓은 문단에 일괄 적용하지 않는다. 엄숙함과 작은 음량을 같은 목표로 취급하지 않는다.
- 질문/관점 전환은 실제 앞뒤 원고를 넣은 Smart, 설명은 normal, 결과 강조는 약한 toneup을 사용한다. 위험에 흥분·축하 감정을 붙이지 않는다.
- 단어마다 쪼개지 않고 문장 또는 자연스러운 절로 묶는다. 단어 하나를 확실히 강조하는 기능이나 감정 강도가 곧 음량이라는 보장은 없다.
- 원문 수치·조건·순서·문장부호를 유지한다. 연출 설명은 발화 본문에 넣지 않는다.

이는 의미별 연출 후보이며 모든 원고를 13구간으로 나누는 규칙이 아니다. 이번 강도값은 청취 미승인 상태로, 기존 승인 기본값을 자동 덮어쓰지 않는다.

## 생성과 검사

- 파일: `outputs/typecast-piljae-pfa-emphasis-1.0x-v1/narration.wav`
- 같은 폴더에 원고, `request.json`, `emotion-plan.json`, `render.py`, 합성 보고서와 검사 보고서를 보존한다.
- 성공한 Compose 합성 1회, 요청 10.597초, 출력 92.610초 / 44.1kHz / 모노 PCM16. 기본 네트워크의 DNS 실패 후 허용된 네트워크로 실행했다. 새 후처리 API는 추가하지 않았다.
- 20줄 원문·순서 일치, 화자·속도·피치·API 목표 음량 유지 확인. 발음·억양의 정확성은 청취 검토가 필요하다.
- 이번 비교는 **후처리 증폭 없이 API 반환 음성 그대로**다. 감정 재배치의 효과를 검토하기 위한 것으로, 전체 음량 검사나 향후 보정 절차를 폐기한 것은 아니다.
- 반환 음성의 최대값 PCM 27샘플은 검사 대상으로 기록하고 임의 보간하지 않았다. 원본과 검사 결과를 보존하며 '무결점 음성' 또는 최종 마스터 승인으로 표시하지 않는다.
- 전체 측정: -18.09 LUFS, +0.15dBTP, LRA 3.4LU. 최대값 구간은 약 34.72초와 75.28초에 모여 있고 각 연속 구간은 1~2샘플이다. 최종 마스터의 피크 여유 검증은 미완료다.
- 로컬 Whisper 교차 확인에서 원고의 설명·숫자·결론 순서가 나타났다. 다만 심방세동·삽입형·항응고·뇌졸중 등 전문어 인식 오류가 있어 이를 실제 오발음이나 정확한 발음의 증거로 단정하지 않는다. 단어 발음과 억양은 청취 확인 대상이다. 인식문을 원고에 덮어쓰지 않았다.
