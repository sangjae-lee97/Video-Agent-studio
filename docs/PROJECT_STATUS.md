새 주제와 재개 작업 모두 [분야 공통 제작 지침](VIDEO_PRODUCTION_GUIDE.md)을 읽는다. 실제 사례에서 얻은 프롬프트 작성·검수·수정 원칙을 이 로컬 Markdown에 유지하고, 편별 상태는 프로젝트 폴더에 기록한다. Notion은 사용자용 진행 요약이다.

## 남은 불확실성

- 다른 주제 원고·저음/속삭임/강한 감정 등에서 동일 규칙의 품질 검증은 미완료다. 현재 방식은 채택됐지만 모든 새 결과를 자동 합격시키지 않는다.
- VAD는 호흡 분류기가 아니다. ASR 전문어·숫자·경계 검토가 필요하며 발화 인식문으로 원문을 바꾸지 않는다.
- 이번 SRT는 파일럿에 맞춘 편집 시각이다. 범용 자동 정렬·전체 영상 자동화는 후속이다.
- 기존 의료 원고의 근거는 PubMed 초록과 Cleveland Clinic 기관 설명 확인 수준이며 NEJM 본문은 미열람이다. 수치의 집단/조건을 보존한다.
- FFmpeg 7.1은 .venv-supertonic/imageio-ffmpeg에 있다. 영상 조립은 이 FFmpeg로, 스트림 검사는 PyAV로 실행했다.
- 음성 승인과 최종 영상 피크·자막·해부학·시청 품질 합격은 별개다.
