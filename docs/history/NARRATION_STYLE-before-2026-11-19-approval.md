## 배치 절차

1. 확정 원고를 읽고 질문, 설명, 핵심 발견, 정정, 위험, 대응, 결론의 실제 전환점을 찾는다. 같은 말투가 자연스러운 문장들은 묶는다. 영상 컷 수나 Flow 기본 3샷과 음성 구간 수를 일치시킬 필요는 없다.
2. 각 구간에 역할·선택 이유·감정·강도·원문 범위를 기록한다. 내용이 애매하면 normal 0.8을 기본으로 한다. 느낌표 하나만으로 toneup이나 강한 감정을 붙이지 않는다.
3. Smart의 `previous_text`/`next_text`에는 실제 인접 원고를 넣는다. 승인된 예시는 앞뒤 최대 두 줄을 사용했다. 첫 구간의 이전 문맥과 마지막 구간의 다음 문맥은 빈 문자열이다. 다른 주제에 심방세동 문맥을 복사하지 않는다. Smart에는 수동 감정 강도 필드를 섞지 않는다.
4. 피치와 속도는 모든 구간에서 기본값을 유지한다. 감정 표현을 위해 임의로 배속을 바꾸거나 후처리로 늘이거나 줄이지 않는다. 원고의 주장·수치·조건·문장 순서도 감정 효과를 위해 바꾸지 않는다.
5. 강조는 핵심 전환에 사용한다. 문장마다 다른 감정을 붙이거나 승리감·공포·슬픔을 과장하지 않는다. 감정 강도를 자동으로 더 높이지 않는다. `happy/sad/angry/whisper` 및 웃음·한숨 효과는 현재 기본값에 포함되지 않으며 소재·사용자 연출 요청상 필요할 때 별도 판단한다.
6. 음성 입력과 연출 메모를 분리한다. 화자명·역할·설명용 괄호는 읽지 않는다. Supertonic 표현 태그를 Typecast에 그대로 넘기지 않는다.

## 이번 승인 원고에 적용한 내용

- 첫 질문: Smart, 다음 연구 소개 두 줄 제공.
- 연구·시술·배정·추적 방법: normal 0.8.

- 선정/검사/항응고 보완과 위험 미해결 조건: tonedown 0.35.
- 효과와 위험을 함께 판단하는 결론: Smart, 실제 앞 두 줄 제공.

## 생성·검토·보존

음성만 필요하면 현재처럼 Compose로 구간을 순서대로 합칠 수 있다. 자막까지 제작할 때는 타임스탬프 포함 합성을 구간별로 받고 실제 음성 길이·휴지에 맞춰 오프셋을 합산한다. Compose 응답에 자막이 있다고 가정하지 않는다.

매 결과에 원고, 설정, 감정 배치 이유, 모델/화자 ID, 결과 파일, 길이, 검증·청취 상태를 남긴다. 원문 누락/순서, 숫자 발음, 구간 경계, 감정 변화의 갑작스러움, 과한 강조, 음량을 확인한다. 파일 구조 검사와 청취 평가는 구분한다. 승인된 파일은 보존하며 재생성 결과가 완전히 같은 소리라고 보장하지 않는다.

이전 합성에서 일부 최대값 PCM 샘플을 보간한 것은 개별 파일 보정 기록이며 기본 감정 설정에 포함하지 않는다. 앞으로 모든 음성을 자동 보간하지 말고 실제 상태를 확인하고 원본을 보존한다. API 호출이나 합성 크레딧 사용 없이 문서/설정만 갱신할 수 있다.

## 로컬 자동화 기준 — 최신 후보, 청취 미승인

최신 적용은 전체적으로 긍정 평가된 감정 재합성본에 대한 후속 보정이다. 사용자가 12~20초의 약음과 문장 첫 0.x초 보호를 지정해 기존 공통 설정(시작/끝 0.2초, 최대 +3dB)을 원본 전체에 적용했다. `docs/piljae-emphasis-local-level-results.json` 참조. 새 후보 청취·다른 원고 검증은 아직이다.

2026-11-19 사용자 결정으로 Auphonic과 추가 후처리 API는 제외했다. 특정 예시 문장에 맞춘 튜닝 대신 다른 원고에도 적용할 규칙을 검증한다. 최신 후보는 같은 스크립트의 `--mode short-window`이며 [로컬 자동화 기준](LOCAL_AUDIO_POLICY.md)에 공통 설정·검사·3개 파일 실행 증거·미검증 범위를 기록했다. 약 200ms 말소리 변화를 주변과 비교하고 최대 +3dB만 올린다. 문장 앞뒤 0.2초 보호 및 애매한 영역 원본 유지, 감쇠·전체 정규화 제외는 유지한다. 특정 문구/시간별 예외는 없다. 과거 구절 방식은 아래 이력으로 남기며 현재 후보와 혼용하지 않는다.

## 주변 말소리 대비 구절 보정 — 이전 후보 이력

2026-11-19 사용자가 주변 말소리와 비교하고 짧은 구절 단위로 완만하게 올리는 방식을 1.0배속 원본에 다시 적용하도록 요청했다. 앞으로의 자동화 기준으로 검토하는 단계다. **고정 -22dB 기준, 첫/마지막 단어 전체 보호, VAD 전후 0.16초 추가 제외는 철회했다.** 현재 후보의 청취 승인은 아직이며 테스트 통과만으로 제작 기본값 확정이라고 쓰지 않는다.

입력은 전체 정규화 전 원본 WAV다. 현재 화자/SSFM 3.1/감정 설정과 향후 기본 속도 1.05배속은 그대로이며, 이번 시험만 기존 1.0배속 원본을 쓴다. 전체 정규화, 큰 소리 압축, 호흡 감쇠, 길이 변경은 하지 않는다.

### 현재 처리 기준

1. 원본 해시가 같은 ASR 단어 시각과 문장 경계를 확인한다. 원문은 인식 결과로 바꾸지 않는다. 이미 수집한 23문장 시각은 추정치이고 청취 검증/정밀 강제 정렬 완료는 아니다.
2. 단어를 약 1.5초 단위 구절로 묶는다. 긴 조합은 2.8초에서 나누고 너무 짧은 마지막 조각은 앞 구절에 붙인다. 문장 의미를 완전히 이해하는 구절 분할이라고 주장하지 않는다.
3. 말소리 감지 확률 ≥0.6인 20ms 프레임을 측정한다. 에너지 바닥은 파일의 말소리 p90보다 30dB 아래로 잡는다. 이것은 작은 발음을 절대 음량만으로 거르는 이전 -22dB 증폭 기준과 다르다. 감지가 애매한 구간은 수정하지 않고 검토 대상으로 기록하며 숨소리라고 확정하지 않는다.
4. 각 구절의 앞뒤 8초 안에 있는 다른 구절들의 말소리 RMS 65백분위를 기준으로 삼는다. 주변과의 차이에서 1dB 여유를 남기고 80%만 보정한다. 최대 +3dB, 계산값 0.5dB 미만이면 유지한다. 모든 기준은 원본에서 계산하며 앞서 보정한 결과를 다음 구절의 기준에 섞지 않는다.
5. 구절에 하나의 게인을 적용하고 구절 경계 0.2초에 부드럽게 진입/복귀한다. 문장 앞뒤 0.2초는 그대로 보호한다. 단어 전체는 제외하지 않는다. 실제 변경 가능 영역은 단어 시각·높은 음성 확률·에너지 바닥을 함께 만족하는 부분이다. VAD 틈에 추가 보호 시간을 붙이지 않으며 실제 허용 영역 안에서만 0.04초 연결을 부드럽게 한다.
6. 변경할 부분의 피크 여유를 확인해 게인을 제한한다. 피크 여유가 부족하면 해당 구절을 유지하고 이유를 남긴다. 변경하지 않은 원본의 피크를 자동으로 낮추지 않는다.
7. 구절별 원본 음량·주변 기준·계산된 게인·출력 실측 변화·보정/유지 이유를 전부 보고서에 남긴다. 문장 보호 구간 및 낮은 확률의 샘플은 원본과 동일해야 한다. 말소리 부족/입력 해시 불일치/잘못된 문장 경계는 실패 처리한다.
