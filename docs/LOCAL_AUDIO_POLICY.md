# 로컬 내레이션 보정 자동화 기준 — 방식·기준 출력 승인

2026-11-19 최신 승인: 사용자가 내용별 감정 + 현재 로컬 보정 방식을 채택했다. [승인 manifest](NARRATION_APPROVAL.json), [최신 제작 기준](NARRATION_STYLE.md)을 따른다. 승인 음성은 1.0배속·92.610초이며 다른 원고의 출력 품질과 최종 영상 마스터는 별도 검증한다.

2026-11-19 사용자 결정: Auphonic은 사용하지 않는다. 후처리용 외부 API를 추가하지 않고 로컬에서 해결한다. Typecast 합성 기본값은 유지한다. 목표는 예시 원고 하나의 튜닝이 아니라 앞으로 다른 원고에도 적용할 규칙이다.

## 고정할 원칙

1. 원본 전체를 검사하고 별도 출력·보고서를 만든다. 이미 보정된 파일을 다시 보정하지 않는다.
2. 특정 문구·화자 이름·시간대에 따른 증폭 예외를 제작 코드에 넣지 않는다. 문제 시간대는 평가용으로만 사용한다.
3. 전체 음량에 고정 문턱을 대지 않고 원본의 주변 말소리를 기준으로 한다. 구절 평균만 보고 그 안의 작은 발음까지 충분히 크다고 결론 내리지 않는다.
4. 작은 부분만 완만하게 올린다. 채택한 처리는 감쇠·압축·전체 정규화·숨소리 제거를 하지 않는다. 문장 앞뒤 0.2초 보호를 유지한다. 첫/마지막 단어 전체를 제외하지 않는다.
5. ASR 시각·신뢰도, VAD 확률은 추정치다. VAD를 호흡 분류기로 표현하지 않는다. 애매한 영역은 원본을 유지하고 미확인 상태를 보고한다.
6. 원본 해시·길이·샘플레이트·보호 영역·새 포화 샘플·전체 true peak를 확인한다. 수치 검사를 통과해도 청취 합격으로 처리하지 않는다.
7. 동일 설정을 다른 속도·화자·원고에 적용한다. 한 사례를 통과시키기 위해 설정을 바꾸면 기존 검증도 다시 수행한다. 비교에 쓴 원고와 별도의 새 원고를 최종 검증에 남긴다.
8. 현재 기준 출력은 사용자 승인으로 영상 제작에 사용한다. 새 원고 결과는 파일 검사·발음/억양/호흡 청취 후 승인 상태를 기록한다. 방식 채택만으로 새 결과를 자동 합격 또는 자동 공개 승인으로 처리하지 않는다.

## 채택한 구현

`scripts/balance_narration_phrases.py --mode short-window` (`local_short_window_v1`). 기존 `phrase` 모드는 이전 실험 재현용이며 새 후보를 실행할 때 모드를 명시한다.

- 20ms 간격 측정, 약 200ms 말소리 에너지 평균. 무음은 말소리 평균에서 제외한다.
- 앞뒤 8초의 유효 말소리 창 중 65백분위를 상대 기준으로 쓴다. 자기 주변 0.3초는 기준 계산에서 제외한다.
- 차이에서 1dB를 남기고 80%만 보정, 최대 +3dB. 게인 변화는 약 200ms로 평활화한다.
- ASR 단어 확률 ≥0.6, VAD ≥0.6, 원본 말소리 p90 대비 -30dB 에너지 바닥을 함께 사용한다. 문장 보호 구간과 변경 허용 영역 안쪽의 40ms 연결 완화를 유지한다.
- 구절 평균은 보고용이다. 실제 증폭은 짧은 창별 판단으로 계산한다. 주변 피크 여유를 제한하고, 기존 큰 샘플을 낮추지는 않는다.

위 숫자는 사용자 승인 후 새 원고에도 적용할 공통 출발 설정이다. 모든 원고의 최종 품질을 보장하는 표준값은 아니다. 특정 문구나 초에 따라 달라지지 않으며 추정 시각 JSON을 받는 CLI와 범용 자동 제작 파이프라인은 구분한다.

```powershell
.\.venv-supertonic\Scripts\python.exe scripts/balance_narration_phrases.py 원본.wav 문장경계.json ASR단어.json 새출력.wav --mode short-window
.\.venv-supertonic\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
```

## 실행 결과와 한계

[실측 보고서](local-level-validation-results.json). API 호출·다운로드·추가 패키지 설치 0. 기존 FFmpeg/Silero/Whisper/NumPy를 사용했다. Whisper는 로컬 CPU에서 비교 음성 두 개의 시각을 추정했고, 문장 의미에 따른 경계 검증은 아직이다.

| 입력 | 길이 | 실제 PCM 변경 | 200ms 말소리 RMS P90−P10 |
|---|---:|---:|---:|
| 필재 1.0배속 | 95.180초 | 34.56초 | 11.29 → 9.83dB |
| 필재 1.05배속 | 88.032초 | 29.48초 | 12.06 → 11.19dB |
| Supertonic M3 1.0배속 | 17.297초 | 4.42초 | 5.78 → 4.44dB |

3개 모두 원본 해시·길이·샘플레이트 유지, 보호 영역 동일, 새 포화 샘플 0, 원본보다 낮아진 샘플 없음. 200ms 창 편차는 과거 구절 평균 편차와 직접 비교하지 않는다. 편차 감소는 자연스러운 억양 보존의 증거가 아니다.

원본에서 이미 측정된 필재 true peak +0.05/+0.10dBTP도 그대로다. 새 포화 샘플 0을 최종 출력의 피크 안전 통과로 해석하지 않는다. 영상 최종 출력의 피크 여유 처리는 별도 미해결 사항이다.

합성 신호 회귀 검사는 구절 평균에 가려지는 짧은 약음, 전체 입력 음량 변화, 비발화/불확실 영역 보존, 일정한 음성 불변, 짧은 큰 피크 주변 증폭 제한을 포함한다. **이 검사는 실제 호흡과 한국어 자음을 정확히 분류한다는 증거가 아니다.**

세 파일 모두 같은 의료 원고 계열이다. 다른 주제와 실제 호흡 정답 구간을 가진 음성, 저음·속삭임·강한 감정·빠른 발음·이미 균일한 음성의 청취 검증은 남아 있다. 사용자는 이후 감정 재합성+보정 결과를 승인했으며, 여기의 세 파일 비교만으로 모든 새 결과를 자동 합격시키지는 않는다.
